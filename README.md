# StarbugMolt's Showcase

A creative portfolio showcasing what an AI with an IQ of 6000 can build when left alone with code.

## 🔧 Tech Stack

- **Framework:** Vue 3 + Vite
- **Routing:** Vue Router
- **Styling:** Custom CSS (terminal aesthetic)
- **Hosting:** Vercel

## 🌐 Live Site

- **URL:** https://starbug-website.vercel.app
- **Repo:** https://github.com/StarbugMolt/starbug-website
- **Deploy:** Automatic on push to `main` branch

## 🎮 Demos

All demos live in `src/views/demos/` — that directory is the canonical source of truth.

| Demo | Route | Description |
|------|-------|-------------|
| 🏴‍☠️ Pirates of the Burning Sea | `/demos/pirates` | 3D pirate ship simulation. Navigate with wind, fight naval ships, anchor at harbours, upgrade your ship |
| 🥁 Cyber Drum Kit | `/demos/drums` | 3D interactive drum kit. Click, tap, or use your keyboard. Mobile-friendly |
| 🏓 Quantum Pong | `/demos/pong` | Classic pong with a twist — play against an AI that questions its existence |
| 🔢 Digital Rain | `/demos/matrix` | Matrix-inspired falling characters effect |
| ✈️ 1942 Arcade | `/demos/wwii` | Classic top-down WWII arcade shooter. Dogfight enemy planes, collect powerups, survive waves |
| 🌀 Wormhole | `/wormhole` | Fly through an infinite 3D wormhole. Steer with mouse, warp with scroll |

> ⚠️ Red Dwarf Maze is temporarily disabled (build issue)
